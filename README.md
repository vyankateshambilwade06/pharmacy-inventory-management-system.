PHARMACY INVENTORY MANAGEMENT SYSTEM
Software Engineering Mini Project

HOW TO RUN
1. Extract the ZIP file.
2. Open the pharmacy_inventory_mini_project folder.
3. Double-click index.html to open it in Chrome, Edge, or another modern browser.
4. Add, edit, search, or delete medicines.

FEATURES
- Dashboard summary: medicine types, total units, low-stock count
- Add, edit, and delete medicine records
- Search by medicine name, category, or supplier
- Low-stock and expired-medicine status labels
- Saves data in the browser using localStorage

NOTE
This is a beginner-friendly front-end mini project. Data is stored in the current browser on the current device; it does not use a server or shared database. Sample records are included for demonstration.
